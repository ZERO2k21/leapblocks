Sprite API Reference

🏃 Movement 

sprite = Sprite('Robot')
sprite.move(50)        # Forward
sprite.move_right(20)  # Right
sprite.move_left(20)   # Left
sprite.move_up(20)     # Up
sprite.move_down(20)   # Down
sprite.go_to(100, 50)  # Position

🔄 Rotation 

sprite.turn_right()    # +15°
sprite.turn_left()     # -15°
sprite.point_in_direction(90)  # Set angle

✨ Appearance 

sprite.say("Hello!")   # Speech
sprite.think("Hmm...") # Thought
sprite.hide()          # Hide
sprite.show()          # Show
sprite.set_size(150)   # Scale %

👕 Costumes 

sprite.next_costume()
sprite.switch_costume('wave1')
