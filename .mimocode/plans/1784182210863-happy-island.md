## How to Add Real Images to the Dataset

### Directory Structure
```
public/assets/neura-datasets/
  animals/
    cat/          → cat_01.jpg, cat_02.jpg, ... cat_10.jpg
    dog/          → dog_01.jpg, dog_02.jpg, ... dog_10.jpg
    bird/         → bird_01.jpg, bird_02.jpg, ... bird_10.jpg
  vehicles/
    car/          → car_01.jpg, car_02.jpg, ... car_10.jpg
    bicycle/      → bicycle_01.jpg, bicycle_02.jpg, ... bicycle_10.jpg
  food/
    apple/        → apple_01.jpg, apple_02.jpg, ... apple_10.jpg
    banana/       → banana_01.jpg, banana_02.jpg, ... banana_10.jpg
  objects/
    cup/          → cup_01.jpg, cup_02.jpg, ... cup_10.jpg
    book/         → book_01.jpg, book_02.jpg, ... book_10.jpg
```

### Naming Convention
**Pattern:** `{subcategory}_{NN}.jpg` where NN is 1-indexed, zero-padded to 2 digits

Examples:
- `cat_01.jpg`, `cat_02.jpg`, `cat_03.jpg` ... `cat_10.jpg`
- `car_01.jpg`, `car_02.jpg`, `car_03.jpg` ... `car_10.jpg`

### Image Requirements
| Property | Value |
|----------|-------|
| Format | JPEG (`.jpg`) only |
| Resolution | 200x200 px recommended (square) |
| Max size | Keep under 100KB per image |
| Quality | 75-85% JPEG quality |

### Where to Get Free Images
1. **Unsplash** (https://unsplash.com) — Free, no attribution required
2. **Pexels** (https://pexels.com) — Free, no attribution required
3. **Pixabay** (https://pixabay.com) — Free, no attribution required
4. **Open Images Dataset** (https://storage.googleapis.com/openimages/web/index.html) — Google's dataset with bounding box annotations

### Quick Guide to Add Images

#### Method 1: Manual Download
1. Go to Unsplash/Pexels/Pixabay
2. Search for "cat", "dog", "car", etc.
3. Download 10 images per category
4. Resize each to 200x200px (use https://www.birme.net or any image editor)
5. Save as JPEG with the correct filename
6. Place in the correct folder

#### Method 2: Batch Download Script
Create a simple script to download from Unsplash API:
```bash
# Example: Download 10 cat images
for i in $(seq -w 1 10); do
  curl -s "https://source.unsplash.com/200x200/?cat" -o "cat_${i}.jpg"
done
```

#### Method 3: Use Existing Images
If you have images on your computer:
1. Resize to 200x200px
2. Convert to JPEG
3. Rename to match the pattern
4. Copy to the correct folder

### File Path Examples
When the user clicks "Download" in the app:
- Fetch URL: `/assets/neura-datasets/animals/cat/cat_01.jpg`
- Browser loads the file from `public/assets/neura-datasets/animals/cat/cat_01.jpg`
- Image is converted to base64 and added to the project class

### Fallback Behavior
If an image is missing from disk:
- The app generates a **placeholder image** (colored geometric shapes with label)
- The download still succeeds (user sees no error)
- Placeholder images work for training but real photos give better results

## Feature 1: Local Image Dataset (Download Tab)

**What**: Add a "Download" sub-tab in Collect mode. Images are stored locally in `public/assets/neura-datasets/` as organized folders. Users browse categories, select quantity, and images are fetched from the local folder (via relative URLs) and added to their project class as base64 samples.

**Architecture**:
```
public/assets/neura-datasets/
  animals/
    cat/
      cat_01.jpg ... cat_10.jpg
    dog/
      dog_01.jpg ... dog_10.jpg
    bird/
      bird_01.jpg ... bird_10.jpg
  vehicles/
    car/
      car_01.jpg ... car_10.jpg
    bicycle/
      bicycle_01.jpg ... bicycle_10.jpg
  food/
    apple/
      apple_01.jpg ... apple_10.jpg
    banana/
      banana_01.jpg ... banana_10.jpg
  objects/
    cup/
      cup_01.jpg ... cup_10.jpg
    book/
      book_01.jpg ... book_10.jpg
```

**Manifest file**: `src/neura/data/imageDatasets.ts` — JSON manifest listing all categories, subcategories, image counts, and preview thumbnails. This is a TypeScript constant, not fetched from an API.

**How it works**:
1. User opens Collect mode → sees Camera | Upload | **Download** tabs
2. Clicks Download → sees category grid (Animals, Vehicles, Food, Objects, etc.)
3. Selects a category → sees subcategories (e.g., Animals → Cat, Dog, Bird)
4. Selects subcategory + quantity (5, 10, 15, 20) → clicks "Add to Class"
5. Images are fetched from `/assets/neura-datasets/{category}/{subcategory}/{filename}.jpg`
6. Each image is converted to base64 via canvas and added as a Sample to the selected class
7. Progress bar shows during fetch/convert

**Files to modify**:

**Note**: Initial dataset will use ~50-100 curated public domain images across 8-10 categories. Images should be small (200-400px) to keep bundle size reasonable. Can be expanded later.

## Plan: Kaggle Dataset Integration

### Overview
Allow users to download images from Kaggle's free public datasets directly in NEURA. Users configure their Kaggle API credentials once, then browse and download from thousands of real image datasets.

### How Kaggle API Works
1. **Authentication required** — Users need a Kaggle account + API token
2. **REST API** — `https://www.kaggle.com/api/v1/datasets/...`
3. **Free tier** — No cost, but requires account
4. **API token** — Username + Key stored in `~/.kaggle/kaggle.json`

### Integration Architecture

```
User clicks "Download from Kaggle"
    ↓
NEURA sends request to Kaggle API
    ↓
Kaggle returns dataset listing / image URLs
    ↓
NEURA downloads images, resizes, adds to class
```

### Implementation Steps

#### Step 1: Kaggle Configuration UI
Add a settings section in NEURA Home or Project Workspace:
- Input fields for Kaggle Username and API Key
- Store in localStorage (encrypted if possible)
- Validate credentials with a test API call
- Show connection status indicator

#### Step 2: KaggleDatasetProvider Service
Create `src/neura/ml/KaggleDatasetProvider.ts`:
```typescript
interface KaggleDataset {
    ref: string        // e.g., "jessicali9530/animal-dataset"
    title: string
    size: number
    imageCount: number
}

class KaggleDatasetProvider {
    private username: string
    private apiKey: string

    async searchDatasets(query: string): Promise<KaggleDataset[]>
    async getDatasetFiles(datasetRef: string): Promise<string[]>
    async downloadImage(url: string): Promise<string> // returns data URL
}
```

#### Step 3: Kaggle Dataset Browser Component
Create `src/neura/ui/components/KaggleDatasetBrowser.tsx`:
- Search bar for dataset queries (e.g., "cat", "car", "fruit")
- Results grid showing dataset previews
- Select dataset → browse images → add to class
- Progress indicator during downloads

#### Step 4: Integrate with Collect Mode
Update `ObjectDetectorPanel.tsx` Download tab:
- Add "Local Dataset" / "Kaggle" toggle
- When Kaggle selected, show KaggleDatasetBrowser
- Same `mode.addSample()` flow for adding images

### Kaggle API Endpoints Used

| Endpoint | Purpose |
|----------|---------|
| `GET /api/v1/datasets/list?search={query}` | Search datasets |
| `GET /api/v1/datasets/download/{owner}/{dataset}` | Download dataset zip |
| `GET /api/v1/datasets/list/{owner}/{dataset}/files` | List files in dataset |

### Authentication Flow
1. User goes to kaggle.com → Account → API → Create New Token
2. Downloads `kaggle.json` file
3. In NEURA, clicks "Connect Kaggle" → enters Username + Key
4. NEURA validates with test API call
5. Credentials stored in localStorage
