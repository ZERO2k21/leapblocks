### Minor Issue Found

**Camera in embed mode**: The `getUserMedia` API requires a secure context (HTTPS or localhost). When the parent page serves LeapLab over HTTP in an iframe, the camera will fail. Our code already handles this gracefully with an error message. No fix needed — this is a browser security requirement.
