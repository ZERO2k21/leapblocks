# Neura ML Dashboard – Premium UI Enhancement Plan

## Goal
Elevate the Neura ML dashboard from "well-designed educational tool" to "polished premium product" with refined animations, micro-interactions, better responsive design, and a cohesive design system.

---

## Issues Found

1. **Broken keyframes** – `flash` and `slideUp` animations referenced but never defined
2. **No staggered entry** – Cards mount simultaneously, no cascade effect
3. **No page transitions** – Instant cuts between NeuraHome and Workspace
4. **No skeleton loading** – Camera/model load has no visual feedback
5. **Missing micro-interactions** – No capture feedback, no card exit animations
6. **Bare Tailwind config** – No custom tokens, no easing curves
7. **Inconsistent focus states** – Mixed ring/border patterns
8. **Unused TopBar.tsx** – Dead code (111 lines)

---

## Implementation Plan

### 1. Fix Broken Keyframes & Add New Animations
**File:** `src/index.css`

Add missing keyframes:
- `flash` – white flash overlay on capture (opacity 0→0.5→0)
- `slideUp` – for add-class input and undo toast
- `stagger-in` – combined fade + slide-up for card cascades
- `capture-pulse` – ring expansion on photo capture
- `confidence-fill` – smooth width fill for confidence bars
- `toast-enter` / `toast-exit` – slide up from bottom, fade out

Add custom easing curves as CSS variables:
- `--ease-bounce: cubic-bezier(0.34, 1.56, 0.64, 1)` for interactive overshoot
- `--ease-smooth: cubic-bezier(0.4, 0, 0.2, 1)` for page transitions
