STEP 2: CONVERT PNG TO SVG
───────────────────────────

Use Adobe Illustrator:

1. File → Place (select PNG)

2. Image Trace Settings:
   ┌─────────────────────────────┐
   │ Mode: Color                 │
   │ Colors: 16-20               │
   │ ✓ Ignore White  ← CRITICAL! │
   │ Paths: 50%                  │
   │ Corners: 75%                │
   │ Noise: 1px                  │
   └─────────────────────────────┘

3. Click "Expand"

4. Object → Ungroup

5. DELETE any black/white background rectangles

6. Object → Group

7. File → Export → Export As → SVG

8. Save with these EXACT names:
   • ayati_walking_ayati_walking-a.svg
   • ayati_walking_ayati_walking-b.svg
   • ayati_walking_ayati_walking-c.svg
   • ayati_walking_ayati_walking-d.svg
