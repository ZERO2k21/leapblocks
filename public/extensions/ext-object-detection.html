📦 Available Blocks
detect objects in camera
Runs the object detection model on current camera frame.
when [object ▾] detected
Fires when the specified object is found.
label of object (1)
Returns the label name of the nth detected object.
confidence of object (1)
Returns the confidence score (0–100) of the nth object.
x of object (1)
Returns the X coordinate of the nth detected object.
y of object (1)
Returns the Y coordinate of the nth detected object.
number of objects
Returns total number of objects detected in current frame.
