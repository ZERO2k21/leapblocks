⚙️ How it works

  1. Click Add to Project — blocks appear in your Pen & Face toolbox
  2. Use 📷 camera on to start the camera on the stage
  3. Use 👤 analyze face to begin detection
  4. Read count faces or guess emotion in your scripts
  5. Uses the browser's built-in FaceDetector API — no external library needed
